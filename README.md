# ***News Explorer:***

Back-end Serverless


---

## 📌 Sobre o projeto
Atualmente, este repositório contém apenas uma **função serverless**, utilizada como suporte ao front-end.  
A arquitetura completa do backend será implementada futuramente. Por isso, este **ainda não representa o backend final** da aplicação.

---

## 🎯 Funcionalidades
Há uma função serverless responsável por:
- 🌍 Proxy da API;
- 🔍 Autenticação da chave API;
- ⏳ Validação de requisições.

## ▶️ Como executar o projeto localmente
```bash
# Clone o repositório
git clone https://github.com/jamesawp1/project-newsExplorer-backend.git

# Acesse a pasta do projeto
cd project-newsExplorer-backend

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```
